# MilliyGram Desktop

MilliyGram Desktop — Windows uchun o'zbekcha Telegram klienti. U rasmiy **Telegram Desktop** ochiq kodi (GPL v3) asosida qurilgan va Telegram API orqali ishlaydi. Telegram FZ-LLC bilan bog'liq emas.

- Yangiliklar: [@MilliyGramm](https://t.me/MilliyGramm)
- Chat: [@MilliyGramChat](https://t.me/MilliyGramChat)
- Android versiyasi: [MilliyGram](https://github.com/rndesign2001-coder/MilliyGram)

## Yuklab olish
**Releases** bo'limidan `MilliyGram-Setup-x64.exe` (o'rnatuvchi) yoki portativ `zip` faylni yuklab oling.

## Yig'ish
Windows x64 versiyasi GitHub Actions'da avtomatik yig'iladi (`.github/workflows/windows.yml`).
Telegram API kalitlari faqat repozitoriy **Secrets** bo'limida saqlanadi: `API_ID`, `API_HASH`.

## Litsenziya
GPL v3 (OpenSSL istisnosi bilan) — `LICENSE` va `LEGAL` fayllariga qarang. Asl loyiha: https://github.com/telegramdesktop/tdesktop
